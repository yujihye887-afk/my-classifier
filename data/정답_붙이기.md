# 정답 붙이기 — 채점용 30

## 2. 칸 (분류)

| 칸 | 기준 |
|---|---|
| 보안 | 해킹 · 악성 메일 · 정보 유출이 의심된다 |
| 계정권한 | 로그인 · 비밀번호 · 접근 권한이 막히거나 필요하다 |
| 장비 | 노트북 · 모니터 · 프린터처럼 손에 잡히는 기기가 고장 나거나 필요하다 |
| 소프트웨어 | 프로그램 설치 · 오류 · 업데이트 |
| 기타 | 위 넷에 들지 않는다 |

**두 칸에 걸칠 때:** 보안 → 계정권한 → 장비 → 소프트웨어 → 기타 순서로 앞 칸을 정답으로 한다.

## 3. 긴급도

| 값 | 기준 |
|---|---|
| 높음 | 지금 일을 못 하거나 피해가 번진다 |
| 보통 | 불편하지만 일은 할 수 있다 |
| 낮음 | 문의 · 요청 |
